# minipdf

realhani.com의 Windows용 가벼운 PDF 리더·간단 편집기입니다. 무료로 사용할 수 있습니다.

## 다운로드

[최신 설치판 다운로드](https://github.com/yeonijae/minipdf/releases/latest)

릴리스의 **minipdf-버전-setup-x64.exe**를 내려받아 실행하세요. Windows 10/11 x64, .NET Framework 4.8 환경에서 동작합니다. 현재 사용자 계정에 설치하며 기본 위치는 %LOCALAPPDATA%\Programs\minipdf입니다.

## 주요 기능

- 필요한 부분부터 읽는 PDF 보기, 페이지·썸네일 이동, 캐시
- 본문 글자를 드래그해 선택하고 Ctrl+C/우클릭으로 복사 (기존 OCR 텍스트 포함)
- 손 도구로 화면 이동, Ctrl+휠 및 Ctrl +/− 확대·축소
- 직선·자유펜·형광펜·사각형·타원, 텍스트와 PNG/JPEG 이미지 추가
- 추가한 객체의 이동·크기·색상·불투명도 조절, 실행 취소·다시 실행
- 지우개(X)로 추가한 객체 클릭/문지르기 삭제, Ctrl+Z로 한 번에 복원
- 이미지·텍스트·도형·펜 객체 Ctrl+C/V 복사, 페이지·탭·창 사이 붙여넣기
- 여러 PDF를 탭으로 열기, 빈 A4 PDF 새 탭, 탭마다 편집 이력·페이지·배율 유지
- 페이지 삭제·빈 페이지/다른 PDF 삽입·탭 또는 창 사이 페이지 복사
- 인쇄 미리보기, 용지 맞춤/실제 크기, 지원 프린터의 양면 인쇄
- 하단바에서 바로 선택하는 화면 화질: 끔 / 보통 / 강하게 / 부드럽게 / Anti-aliasing
- Windows PDF 연결 설정, 새 버전 확인 및 알림

문서를 열면 손 도구로 시작합니다. 첫째 줄에 도구와 현재 도구의 속성을 함께 표시합니다. 파일명은 둘째 줄의 문서 탭에서 확인합니다. 기본색·채우기·텍스트 배경색과 정렬 버튼을 직접 선택하며, 창이 좁으면 속성의 좌우 버튼이나 휠로 나머지 항목을 봅니다. 설정 → 보기에서 자동 표시 여부를 바꿀 수 있습니다.

새 PDF는 기존 문서를 닫지 않고 새 탭에 추가합니다. Ctrl+T 새 탭, Ctrl+W 탭 닫기, Ctrl+Tab/Shift+Tab 탭 전환, Ctrl+N 별도 창을 지원합니다. 닫을 때 미저장 내용을 확인합니다. 탭은 현재 실행 중에만 유지합니다.

본문 글자는 **본문 글자 선택(S)** 도구로 드래그한 뒤 Ctrl+C 또는 우클릭으로 복사합니다. Ctrl+A는 현재 페이지 전체 선택, Esc는 해제입니다. 마우스를 놓거나 확대해도 선택 표시를 유지합니다. 이미지 스캔본은 기존 OCR 텍스트가 있어야 하며, 복사 금지 PDF에서는 도구가 비활성화됩니다.

객체를 복사하려면 선택 도구(V)로 클릭하고 Ctrl+C, Ctrl+V를 누릅니다. 썸네일에 포커스가 있으면 기존 페이지 복사를 수행합니다. 지우개는 추가한 편집 객체 전체를 지우며 기존 PDF 본문에는 적용되지 않습니다. 설정은 ☰ → 설정 또는 Ctrl+,로 엽니다.

하단 **화질** 목록에서 화면 처리를 바로 바꿀 수 있습니다. 선택은 즉시 반영하고 기억하며 설정 → 보기와 같은 값을 사용합니다. 원본 PDF·저장·인쇄 결과는 바뀌지 않습니다.

## 버전·업데이트

현재 버전은 설정 오른쪽 위 또는 ☰ → minipdf 정보에서 확인합니다. 설정 → 업데이트 → 지금 확인으로 공개 정식 릴리스를 확인할 수 있습니다. 0.1.18 이하에서 업데이트 확인에 실패하면 이 페이지의 최신 설치판을 직접 내려받아 설치하세요. 새 버전이 있으면 배포 페이지를 안내하며, 설치 파일은 사용자가 내려받아 실행합니다.

## 사용 범위

기존 PDF 본문·주석 편집, OCR, 텍스트 검색은 제공하지 않습니다. 추가한 선·텍스트·이미지는 저장 시 PDF 본문에 반영되며, 문서를 닫고 다시 열면 개별 편집할 수 없습니다. 현재 세션에서는 저장 후에도 편집과 실행 취소가 가능합니다. 암호 또는 디지털 서명이 있는 문서는 읽기 전용이며 편집 도구가 회색으로 표시됩니다. 비활성 도구에 마우스를 올리면 이유를 볼 수 있습니다.
